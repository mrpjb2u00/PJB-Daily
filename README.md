# PJB Daily

PJB Daily is an Expo React Native productivity app built with TypeScript, Expo Router, and Supabase. The app centers on calendar-based planning with To-Dos, Notes, Daily Briefing, Profile, recurring tasks, authentication, dark mode, and responsive UI polish.
